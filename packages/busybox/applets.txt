# The busybox applets this image ships, and no others. build.sh turns off
# every applet not named here and refuses a binary whose `busybox --list`
# differs from this file; tools/check-applets.py, in `make lint`, refuses an
# on-device script that runs a command neither here nor elsewhere in the
# image. Features stay as defconfig and config.fragment set them.
#
# A missing applet is not a build error: it is "applet not found" on
# stderr and an empty pipeline, at run time, on the stick. So an applet
# leaves this list only when nothing below still names it.
#
# Names, separated by blanks; # starts a comment.

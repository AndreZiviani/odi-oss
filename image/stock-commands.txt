# Commands available on the STOCK vendor image, which is what image/fwu.sh has
# to run on for the FIRST flash. Anything not in this list is not there, and a
# missing command does not fail loudly: the pipeline yields empty, empty reads
# as "no data", and fwu.sh reported "no MTD partition named k1" -- accusing the
# flash map.
#
# Derived from the 96 entries of /bin on the V1.0-220923 rootfs: 52 busybox
# 1.12.4 applet symlinks plus real vendor binaries. /sbin is a symlink to /bin,
# so there is no second directory to check -- and note that resolving that
# symlink with the rootfs merely unpacked on a host escapes the tree and finds
# the HOST's binaries, which is how dd was first misread as present.
#
# Notably ABSENT: head wc dd tail tr sort which basename dirname seq xargs
# find stat env readlink. `command -v` is absent too: the ash builtin table
# does not carry it ("ash: command: not found", measured under qemu-mips).
# `printf` IS available as an ash builtin despite having no /bin entry.

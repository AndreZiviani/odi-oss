# Security policy

## Supported versions

Only the latest release is supported. Security fixes ship as a new release;
there are no patches for older ones. Update by flashing the new image the way
`docs/FLASHING.md` describes. Nothing updates a stick by itself.

## Reporting a vulnerability

Report it privately through GitHub private vulnerability reporting:
<https://github.com/AndreZiviani/odi-oss/security/advisories/new>

Please do not open a public issue or pull request for it. Say which release
you tested, what you did and what happened. If you have a fix or a way to
reproduce it on a stick or under qemu, include it.

This is a small project maintained by one person, so there is no response
deadline. Reports are read and answered as soon as possible. Once a fix is
released, the advisory is published and credits the reporter unless they
prefer not to be named.
